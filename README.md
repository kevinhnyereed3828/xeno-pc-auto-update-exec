## About Xeno PC

Xeno PC is a Windows desktop application for executing Roblox Lua scripts. It uses a streamlined interface so users can work with scripts, queues, and updates without navigating a crowded layout.

The application centers on a built-in script hub containing more than 500 scripts. It also supports batch execution, a persistent SQLite-backed queue, automatic updates, and multiple interface languages for users who want a local Roblox script executor with a practical desktop workflow.
